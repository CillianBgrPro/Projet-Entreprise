# Projet entreprise pour le CHU d'Orléans

## Information importante
Le projet utilise un backend Django lancé à partir de Docker.

Il est nécessaire pour le fonctionnement de ce projet d'ajouter un fichier d'environement (.env) avec:
- RESEND_API_KEY=re_nomDeLaClé

## Description du projet
Site vitrine et front end d'un projet de création de cas pratiques virtuels pour aider les étudiants de médecine.
